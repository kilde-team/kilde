## 0.18.0 の改善

- **App Store 版に «アプリを応援» (チップ) を追加しました** (issue #171)。パネルの最下部から 3 種類の金額のチップを送れます。録画・文字起こしのすべての機能は従来どおり無料で、ご支援は開発に使わせていただきます
- **この変更は App Store 版のみです**。直接配布 (DMG) 版の UI・録画の挙動は 0.17.0 から変わりません (チップの購入は App Store の仕組みを使うため、DMG 版には含めていません。DMG 版の導線は GitHub Sponsors の参加後に別途追加する予定です — issue #171 の残りのスコープ)
