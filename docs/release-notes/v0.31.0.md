# 0.31.0

## 文字起こしの言語選択の改善 (macOS 26 以降の機能)

- **文字起こしの言語一覧が、この Mac で文字起こしに対応している言語すべてを表示するようになりました** (issue #486)。設定ウィンドウ («文字起こしの詳細») の言語一覧は ja-JP / en-US の固定 2 言語でしたが、SpeechTranscriber が対応している言語がすべて並びます (日本語・英語は先頭、残りはローカライズ名の辞書順)。まだ取得していない言語モデルには «未取得» を表示します (文字起こしの実行時に取得します)
- **«端末の言語設定» の言語が文字起こし非対応の Mac でも、録画後の文字起こしが失敗しにくくなりました**。従来は端末の言語が SpeechTranscriber 非対応だと、録画は成功したのに文字起こしだけ unsupported_locale で確実に失敗していました。0.31.0 からは «自動» と同じ録音の冒頭からの言語判定にフォールバックし、**すべての音声トラックで判定できたときだけ**その言語で書き起こします
- **判定できなかったときは文字起こしをせず、対応言語を選ぶ案内を失敗通知に出します** (生のエラーコードの代わり。音声トラックが読めない録画など、判定の対象にならない失敗は従来どおりのエラー表示です)。設定ウィンドウでは、選択中の言語がこの環境に無いときに警告を表示し、明示した言語が «録音全体をその言語で書く» ものだと案内します
- 言語モデルが未取得の言語に判定された場合は、従来の固定言語と同じく Apple からモデルがダウンロードされます (一般的なネットワーク通信と同じく IP アドレスは Apple に伝わります — PRIVACY.md «文字起こしの言語モデル» 参照)

## その他

- 録画エンジン (KildeCore) の変更はありません (エンジン pin は v0.22.0 のまま)
