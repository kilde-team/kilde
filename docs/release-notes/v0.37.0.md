# 0.37.0

## 録画ライブラリから録画の名前を変えられるように

- **録画ライブラリで録画の名前を変えられるようになりました** (issue #532)。溜まった会議の録画を «kilde-yyyyMMdd-HHmmss» の自動生成名のまま抱え込まず、«kilde-定例会議» «kilde-経営会議11月» のような、あとで見て何の会議か分かる名前に変えられます。一覧の録画を右クリック、または詳細の右上のボタンから実行します
- **録画と一緒に、同じ名前の文字起こし・議事録のファイルも同じ名前に変わります** (.json / .md / .txt / .srt / .vtt と枝番) — 文字起こしのリンクは名前で結ばれているため、「録画だけ名前が変わって文字起こしが外れる」ことを避けます。拡張子と枝番 (`-2` など) はそのまま保たれます
- **名前の先頭の «kilde-» は残ります** (例: `kilde-定例会議.mov`)。ライブラリの一覧は «kilde- で始まる録画» を対象にしているためです (保存先フォルダには kilde 以外の動画も混ざりうるので、その絞り込みがライブラリの守りになっています)。ダイアログの入力欄には «kilde-» 込みの現在名が入っているので、後ろを書き換えるのが簡単です。«kilde-» を消して入力した場合も、自動で付け直します
- **ほかの録画のファイルは変わりません** — 同じ名前の録画形式のファイル (たとえば取り込みで名前が重複した `-2.m4a`) が隣にいるとき、その録画のサイドカーは «そちらのもの» として残ります。ゴミ箱移動 (0.36.0) と同じ «この録画のもの» の区別です
- **同じ名前のファイルがすでにあるときは、何も変えずに案内します** — 変えようとした名前と同じ stem のファイルが保存先にあるときは «同じ名前のファイルがあるため名前を変更できません» と出て、録画も文字起こしも元の名前のままです (上書きや «録画だけ変わり文字起こしが外れる» を防ぐため)。入力した名前が使えないとき (空・`/` や `:` を含む・先頭が `.`・長すぎる) も案内が出ます
- **文字起こしの実行中・待機中の録画と、録画中の録画は変えられません** — 処理中・書き込み中のファイルの名前を変えないため、導線が無効になります
- リネーム後はライブラリの表示が新しい名前に切り替わり、**選択していた録画の詳細もそのまま新しい名前で開きます**。Spotlight への反映は既存の差分同期が行います (旧名の削除と新名の追加は、同期の実行時に反映されるため、すぐには出ないことがあります)
- 一部の関連ファイルだけリネームできなかったときは、録画の名前は変わって、その旨を詳細に案内します (黙って失敗しません)。保存先フォルダが読めなかったときは何も変えずにその旨を案内し、移動に失敗したとき (権限の無い保存先・ネットワークボリュームなど) は «Finder で名前を変更してください» の案内が出ます
- 処理の対象は、その録画と同じ名前のファイルだけです。録画の内容が端末の外へ送られることはありません

## その他

- 録画エンジン (KildeCore) の変更はありません (エンジン pin は v0.22.0 のまま)
