# 0.38.0

## 録った会議の文字起こしに質問できるように

- **録画ライブラリで、録画の文字起こしについて質問できるようになりました** (issue #540 — 第四弾 Pro)。詳細ペインの «質問する» から «この会議で決まったことは?» のように質問すると、その録画の文字起こしから答えを探して表示します。対象は文字起こしを持つ録画で、文字起こしが無い録画は «文字起こしを作成» で作ってから使えます
- **長い文字起こしでは、答えの根拠になる文字起こしの行も表示します** — 区間ごとに質問に関連する行を原文のまま抜き出してから 1 つの答えにまとめるため、«どこに書いてあったか» をたどれます。抜き出す行は文字起こしの原文と照合してから使うので、根拠は文字起こしに書いてある行だけです。1 回の呼び出しに収まる長さの文字起こしでは全体を直接見て答えるため、根拠の表示は出ません
- **質問と文字起こしは端末の外へ出ません** — Apple Intelligence のオンデバイス処理 (macOS 26 以降) です。Apple Intelligence が使えない環境では «質問する» が無効になり、理由がツールチップに表示されます
- **質問応答は Pro の機能です** (第四弾) — 買い切り 1 商品 (kilde.pro) で要約・フォローアップの下書き・カスタム指示・質問応答のすべてがアンロックされ、**すでに Pro を購入済みの場合は追加購入なしで使えます**。未購入のときは «質問する» が無効になり、設定パネルから購入できます («控えめ» 方針 — 購入導線は設定パネルにしか置いていません)。設定パネルの «カスタム指示» は質問応答にも反映されます
- 回答は «コピー» できます (根拠の行も一緒にコピーされます)。質問を変えて何度でも実行でき、シートを閉じると実行中の生成は止まります
- その他: 録画エンジン (KildeCore) を v0.23.1 に更新 (質問応答のエンジン実装 kilde-cli-swift#141 と、長い文字起こしの抽出でモデルが時刻接頭辞を落とした抜粋を返したときの照合修正 kilde-cli-swift#143)。録画の挙動 (収録・文字起こしの実行) に変更はありません
