## App Store 検索キーワードを見直し (5 ロケール)

- **アプリ名・サブタイトルに既出の語をキーワード欄から除去** (Apple 公式ガイド:
  重複語の排除 — 欄内の語はアプリ名・サブタイトルと組み合わせて照応されるため、
  重複は文字数の無駄)。en は `screen capture` / `transcription` 等、ja は
  「システム音声」「文字起こし」「画面録画」等、ko は `녹화` / `전사` 等、
  zh は `屏幕录制` / `转写` 等、es は `grabadora de pantalla` 等を外した
- **空いた上限に高意図語を追加**: 録音系 (ボイスレコーダー / 녹음기 / 录音笔)、
  文字出力 (字幕 / SRT / subtítulos / 音声認識 / 음성인식 / 语音识别)、
  使用場面 (通話 / 講義 / lectures / clase / 통화녹음)
- **複数形・カテゴリ名・`app` を避ける** 方針を踏襲
- 上限: ja は実績のある 180 バイトかつ 100 文字以内 (63 文字 / 155 バイト)、
  他ロケールは 100 バイト以内 (en 95 文字 / ko 93 バイト / zh 96 バイト /
  es 81 バイト)
- 説明・サブタイトル・アプリ名・スクリーンショットは不変
- **他社商標・Apple 製品名は使っていません** (Guideline 5.2.5 / 2.3.7 — README
  の商標チェックコマンドが 0 件)
