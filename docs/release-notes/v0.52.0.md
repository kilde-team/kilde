# 0.52.0

メンテナンスリリース。**録画・文字起こしなどアプリ本体の挙動は変わりません。**
0.51.0 と比べたアプリの変更はありません (エンジン pin も v0.28.0 のまま)。
この版の変更はリポジトリ内の計測台帳の整備です (kilde#639、エピック
kilde#161 / #174 関連)。

## この版の内容

リポジトリ側 (docs) のみの変更で、配布物のアプリは 0.51.0 と同じ内容です:

- **月次締めチェックリストの新設** (docs/metrics.md): GA4 月次行・ASC 週次表・
  IAP 販売数月次台帳・評価件数の «取得元 / 集計窓 / 記入先 / 未取得時の扱い» と
  月末〜月初の締め順序を整備しました
- **未取得項目の扱いの明文化**: «未記入 (取得待ち)» / «未取得» を理由つきで
  書き、推測値を書かない。母数 < 100 の率は pooled 比を参考併記し、当月窓の
  率での判定は «判定不可» としました
- **#161 出口条件 («録画完了MAU 1,000・評価 30 件») の判定欄を雛形で新設**
  (#174 は 0.51.0 で整備済みの既存判定欄を参照)。実測値の記入は 2026-11 月次
  振り返り時に行い、本版では埋めません
- docs/appstore/metadata/metrics.md に 0.51.0 の承認日 (2026-11-25 JST) を記入
- ユーザーに見えるアプリの変更はありません — 0.51.0 の録画・文字起こし・
  要約・Pro 機能 (7 種) はそのままです

  コードの変更はありません
