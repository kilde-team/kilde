# 0.24.0

## 0.24.0 の改善

- **利用統計とクラッシュレポートの送信を、アプリの設定でオフにできるようになりました** (issue #435)。メニューバーのパネルの「プライバシー」にある「アプリの利用統計とクラッシュレポートを送信する」のチェックを外すと、その場で両方の送信を止め、端末に残っている未送信のクラッシュレポートを削除します。オフのまま起動したときは解析の仕組み (Firebase) 自体を初期化しません。オンに戻すとすぐに再開します
- 既定はオン (これまでと同じ) で、収集する内容も変わりません — 録画・文字起こしの内容やファイル名は、設定に関わらずこれまでどおり送信されません (PRIVACY.md 参照)。直接配布版・Mac App Store 版の両方に同じ設定があります。`kilde` コマンドラインは元から何も送信しません

## 内部の変更

- エンジン (kilde-cli-swift) の変更はありません (pin は v0.19.0 のまま)
- 設定の保存・復元と起動時のゲートはセルフテスト `KILDE_GUI_SELFTEST_TELEMETRY` で機械検証できます (docs/DEVELOPMENT.md §3)
