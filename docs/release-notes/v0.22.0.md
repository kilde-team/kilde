# 0.22.0

## 0.22.0 の改善

- **既存の音声・動画ファイルを取り込んで文字起こせるようになりました** (issue #416)。ライブラリの「ファイルを取り込む…」で選ぶか、ライブラリウィンドウにドロップするだけ — kilde を使い始める前や他のツールで録った会議も、端末内の文字起こしと全文検索の対象になります
- 取り込んだファイルは保存先フォルダに `kilde-<日時>-<元のファイル名>` としてコピーされます (元のファイルは変更しません)。同じファイルを再び取り込んでも重複は作りません
- 取り込み後の文字起こしは「文字起こしを作成」と同じ挙動です (言語・書式は設定の値。要約は付きません — 要約が欲しいときは取り込んだ録画の「議事録を作成」を使ってください。議事録には Apple Intelligence が有効な環境が必要です)
- 対応形式: mov / mp4 / m4v / m4a / mp3 / wav / aif / aiff / caf / aac。取り込んだファイルは「最近の録画」とライブラリにも並びます
- 文字起こしには従来どおり macOS 26 以降・対象言語の音声データ (言語モデル) が必要です (モデルが未取得の場合は Apple からダウンロードされます。一般的なネットワーク通信と同じく、その際に IP アドレスは Apple に伝わります — PRIVACY.md「文字起こしの言語モデル」参照)
- 録画が終わった後にメニューバーのパネルを開き直すと、録画中のコンパクト表示の高さのまま戻ることがあった問題を修正しました (issue #417 / PR #419)

## 内部の変更

- エンジン (kilde-cli-swift) の変更はありません (pin は v0.19.0 のまま)
- 取り込みの本体 (コピー・重複判定・名前の組み立て) はセルフテスト `KILDE_GUI_SELFTEST_LIBRARY_IMPORT` で機械検証できます (docs/DEVELOPMENT.md §3)
