## 0.16.0 の改善

- **ポップオーバーから実行中のアプリを選ぶと、そのアプリの音だけを収録できるようになりました** (issue #364)。«音声» セクションの «アプリの音声» で、実行中のアプリをアイコン付きのメニューから選びます。この機能には macOS 15 以降が必要です (macOS 14.x では «アプリの音声» は表示されません)
- 選んだアプリの音声は**マイクと一緒に**録れます (アプリの音声とシステム音声は同時には収録できません — アプリを選ぶとシステム音声が外れます)。アプリの選択は**パネルから録画を開始したときに保存され、次回の起動にも引き継がれます** («この音声・保存先の選択を既定にする» でも保存されます)。選んだアプリが実行中でない場合は、ピッカーに «(実行中でない)» と案内が出て、録画を開始すると «アプリ "…" が実行中に見つかりません» で失敗します (システム音声に黙って縮退することはありません)
