# 0.21.0

## 0.21.0 の改善

- **文字起こしの言語設定に「自動 (録音から判定)」を追加しました** (issue #409、エンジン kilde-cli-swift#131)。選ぶと録音ファイルの音声トラックごとに冒頭 30 秒から会議の言語を判定し (候補は端末の言語・日本語・英語)、その言語で書き起こします
- 音声トラックを分けて録った会議 (分離トラック) では、相手のトラックと自分のマイクのトラックをそれぞれの言語で書き起こします — 例えば «英語の会議 + 日本語で発話する自分» の録音が初めて両方正しく残ります
- 判定できなかったとき (録音の冒頭に発話が無い等) は従来どおり端末の言語設定を使います。**初期設定は変わらず «端末の言語設定» のまま**です (自動判定はオプトイン)
- 処理はすべて端末内 (Apple SpeechAnalyzer) で行われ、音声がネットワークに送信されることはありません。新しい権限も不要です
- CLI (`kilde rec` / `kilde transcribe`) は `--locale auto`、設定ファイルは `locale = "auto"` で同じ挙動になります

## 内部の変更

- エンジン (kilde-cli-swift) の pin を v0.18.0 → **v0.19.0** に更新 (PR #133 相当の
  カレンダー連携に続き、#131 のロケール自動判定を取り込み)
- 判定の設計と実測 (誤ロケールの確定結果は低 confidence になる、など) は
  kilde-cli-swift の SPIKE-NOTES F-Q に記録
