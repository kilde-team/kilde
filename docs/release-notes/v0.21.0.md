# 0.21.0

## 0.21.0 の改善

- **文字起こしの言語設定に「自動 (録音から判定)」を追加しました** (issue #409、エンジン kilde-cli-swift#131)。選ぶと録音ファイルの音声トラックごとに冒頭 30 秒から会議の言語を判定し (候補は端末の言語・日本語・英語)、その言語で書き起こします
- 音声トラックを分けて録った会議 (分離トラック) では、相手のトラックと自分のマイクのトラックをそれぞれの言語で書き起こします — 例えば «英語の会議 + 日本語で発話する自分» の録音を、それぞれの言語で書き起こせるようになります (判定の誤りは手動ロケールで上書きできます)
- 判定できなかったとき (録音の冒頭に発話が無い等) は従来どおり端末の言語設定を使います。**初期設定は変わらず «端末の言語設定» のまま**です (自動判定はオプトイン)
- 録音や書き起こしの内容がネットワークに送信されることはありません (新しい権限も不要です)。言語モデルが未取得の言語に判定された場合は、従来の固定言語と同じく Apple からモデルがダウンロードされます (一般的なネットワーク通信と同じく IP アドレスは Apple に伝わります — PRIVACY.md «文字起こしの言語モデル» 参照)
- CLI (`kilde rec` / `kilde transcribe`) は `--locale auto`、設定は `kilde config set locale auto` で同じ挙動になります
- 文字起こしには従来どおり «録画後に文字起こし» 設定の有効化と、macOS 26 以降・対象言語の音声データ (言語モデル) が必要です

## 内部の変更

- エンジン (kilde-cli-swift) の pin を v0.18.0 → **v0.19.0** に更新 (#131 の
  ロケール自動判定を取り込み)
- 判定の設計と実測 (誤ロケールの確定結果は低 confidence になる、など) は
  kilde-cli-swift の SPIKE-NOTES F-Q に記録
