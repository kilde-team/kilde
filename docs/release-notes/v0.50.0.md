# 0.50.0

メンテナンスリリース。**録画・文字起こしなどアプリ本体の挙動は変わりません。**
この版の変更はリリース基盤 (App Store 提出経路) の信頼性改善です (kilde#633、
kilde#470 関連)。

## この版の内容

- **MAS (App Store) 提出経路の fail-fast 化** — m1 CI ランナーで
  «Archive 中の CodeSign が鍵アクセスの対話認証待ちで沈黙し、無出力 12 分の
  watchdog 打ち切り → job 上限級の停滞» を繰り返していた問題 (kilde#470) に対し、
  アーカイブの直前に署名鍵へのアクセスを bounded に実際に試す preflight
  (`scripts/release/codesign-preflight.sh`) を追加しました。沈黙を検出したら
  «鍵アクセス起因» と分かる診断 (`[keychain]` / `[identity]` / `[proc]`) を出して
  即失敗します — 診断ブロックは署名試行の沈黙 (rc=2) のときだけ出力され、
  identity 列挙自体の沈黙 (rc=1) は診断なしで失敗します。合否の上限は
  **identity 数 × 90 秒** (m1 の実構成は対象 identity 1 個なので最大 90 秒 +
  診断数秒) で、watchdog の 12 分を消す前に確定します。
  失敗時は watchdog の打ち切りを待たずローカル代替経路へ即切り替えできます
- **即時フォールバックの判断基準を文書化** — preflight 失敗なら即切り替え、
  Archive 開始後の無出力が 6 分 (watchdog 閾値の半分) を超えたら打ち切りを
  待たずに切り替えてよい、という基準を docs/RELEASE.md §7
  «停滞時の即時フォールバック» に明記しました
- ユーザーに見えるアプリの変更はありません — 0.49.0 の録画・文字起こし・
  要約 (TranscriptStash による退避と回復) はそのままです

## リリース基盤

- `scripts/release/codesign-preflight.sh` を追加。キーチェーンの有効な
  codesigning identity で一時ファイルへの署名を実際に試し、
  «鍵の可視性はあるが使用時に対話待ちで沈黙する» 状態 (kilde#470 の残仮説) を
  合否判定します。証明書の失効・新規作成、鍵素材・partition-list の変更は
  行いません (m1 実機での恒久対処はオーナー操作 — kilde#470 に記録)
- `.github/workflows/mas.yml` の upload 経路に preflight step を追加
  (アーカイブ step が実行されるときだけ)。0.46.0 の冪等化
  (既存 build の再利用・提出済み版のスキップ — kilde#615) と 0.48.0 の
  観測性改善 (watchdog 打ち切り時の診断とログ退避 — kilde#623 / PR #624 / #625)
  は変わりません
