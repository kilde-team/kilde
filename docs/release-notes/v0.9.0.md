## 0.9.0 の改善

- **録画の自動リスタート**: ディスプレイの接続・解像度の変更などで画面キャプチャが中断されても、自動で再開して同じファイルに録画を続けます (上限 3 回)。自動で再開できなかった場合は、これまでどおり中断時点までの内容を保存してお知らせします (#304 / エンジン v0.9.0)
- **収録の中断の検知と通知**: 画面キャプチャが自停止したとき、録画をそこまでの内容で確定し、その旨を通知でお知らせします (#298)
- **録画の完了画面と「最近の録画」に「フォルダを開く」ボタン**を追加しました (#296)
- **文字起こしの安定性**: 一時的な文字起こしの失敗を自動で 1 回リトライします (#221)。録画途中で保存先を変更した場合も、予約済みの文字起こしを正しく処理します (#230)
- **CLI**: `kilde audio monitor teardown` が状態ファイルを失っても、残留したマルチ出力デバイスを解体できるようになりました (kilde-team/kilde-cli-swift#75)
