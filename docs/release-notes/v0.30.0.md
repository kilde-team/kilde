# 0.30.0

## メニューバーパネルの再構成

- **メニューバーのパネルを «録画の直前に触るもの» に整理しました** (issue #478)。パネルに残るのは収録対象・音声ソース・保存先・«録画後に文字起こし» と要約のトグル (要約は **Mac App Store 版では Pro、直接配布版では無料**)、録画状況と進捗、最近の録画、Rec / Stop です。配置は GA4 の利用統計 (直近 30 日のイベント別ユーザー数 — 記録は issue #478 のコメント) に基づいて決めています
- **«設定» ウィンドウを新設し**、«1 回設定すればよい» 項目をそこへ集約しました。パネル右上の **歯車** ボタンで開きます。移設した項目: 複数の音声ソース (合成 / 分離)、文字起こしの詳細 (言語・出力形式・要約テンプレート・カスタム指示・議事録の書き出し先)、グローバルホットキー、ログイン時に起動、会議の自動録画、録音の告知文、プライバシー (利用統計 / クラッシュレポート)、アプリを応援。直接配布版の «アップデート» の確認も設定ウィンドウへ移りました
- **設定の値と録画の挙動は変わりません**。保存済みの設定はそのまま引き継がれ、変更は項目に応じて保存されます (ほとんどの項目は即時に、グローバルホットキーは **適用** を押したときに保存されます)。設定ウィンドウの文字起こしの詳細は、言語・出力形式などは «録画後に文字起こし» がオンのとき、要約テンプレートは要約が有効なときに編集できます (カスタム指示は Pro があれば文字起こしのトグルにかかわらず編集できます)

## その他

- 録画エンジン (KildeCore) の変更はありません (エンジン pin は v0.22.0 のまま)
