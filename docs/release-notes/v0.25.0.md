# 0.25.0

## 0.25.0 の改善

- **直接配布 (DMG) 版の «アプリを応援» から GitHub Sponsors を開けるようになりました** (issue #171)。App Store 版のチップ (0.18.0) と対称の導線で、直接配布版は Sponsors へのリンクのみ — ボタンは既定ブラウザで Sponsors のページを開くだけで、この操作のために kilde が新しく通信することはありません (更新確認や利用統計といった既存の通信に変わりはありません)
- リポジトリに FUNDING.yml を追加し、GitHub に Sponsor ボタンが表示されます (行き先はアプリ内のリンクと同じです)
- **この変更は直接配布版とリポジトリのみです**。App Store 版の UI・録画の挙動は 0.24.0 から変わりません (App Store 版の «アプリを応援» は 0.18.0 からある App Store の仕組みをそのまま使います)
- 録画・文字起こしのすべての機能は、これまでどおり無料です

## 内部の変更

- エンジン (kilde-cli-swift) の変更はありません (pin は v0.19.0 のまま)
