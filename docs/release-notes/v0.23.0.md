# 0.23.0

## 0.23.0 の改善

- ユーザーに見える機能変更はありません。**このリリースはメンテナンスリリースです** (issue #426)。App Store の製品ページに掲載するプレビュー動画 (日本語 / 英語) の登録を受けるためのバージョンです — バージョンの素材は審査中・公開中はロックされるため、0.20.0〜0.22.0 への登録はできず、次バージョン作成直後が最初の機会でした (issue #160)

## 内部の変更

- ライブラリ取り込みのドロップ経路 (NSItemProvider の収集) をセルフテストで機械検証できるようにしました (issue #424 / PR #425 — 動作の変更は無く、検証の強化のみ)
- エンジン (kilde-cli-swift) の変更はありません (pin は v0.19.0 のまま)
