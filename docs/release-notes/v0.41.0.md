# 0.41.0

## 録った会議の文字起こしを、選んだ言語へまるごと翻訳できるように

- **録画詳細の «翻訳» から、録った会議の文字起こしを、選んだ言語へまるごと翻訳できるようになりました** (issue #564 — 第七弾 Pro、エンジン kilde-cli-swift#149)。翻訳先は日本語 / English / 简体中文 / 한국어 / Español の 5 言語です。«スペイン語の参加者に会議の内容を伝えたい» «英語の資料として持ち出したい» のように、録った会議を別の言語で読む・共有するときに使えます
- **時刻表示 ([MM:SS]) は原文のまま残ります** — 翻訳の行が原文のどの行に当たるかを読める形にするための約束で、エンジンの指示 (kilde-cli-swift#149) が «時刻表示と話者名を翻訳せずそのまま保つ» «元の行の構造を保つ» «原文に書かれていない内容を追加しない» を指定します。翻訳と原文を並べて読みたいときは、«文字起こし» で原文を開いて見比べられます
- **«最後に使った言語» を覚えて、次回の既定にします** — 毎回同じ言語へ翻訳するときの操作が 1 回で済みます (記憶はこの Mac の中だけ。設定パネルには項目を置かず、シートの中の言語選択で変えます)
- **翻訳は «コピー» で全文を持ち出せます** — メールやドキュメントに貼って使います。言語を変えたときは前の言語の結果を消して、選んでいる言語の翻訳だけを表示します (実行中の翻訳は進捗が見え、シートを閉じると止まります)
- **質問と文字起こしは端末の外へ出ません** — Apple Intelligence のオンデバイス処理 (macOS 26 以降) です。Apple Intelligence が使えない環境では «翻訳» が無効になり、理由がツールチップに表示されます (**Apple Intelligence が使えない環境では Pro を購入しても «書き起こしの翻訳» は無効のままです** — ロックが解除されても無効理由の案内は表示され続けます)
- **書き起こしの翻訳は Mac App Store 版の kilde Pro (買い切り ¥2,800) に含まれます** (第七弾) — 買い切り 1 商品で要約・フォローアップの下書き・カスタム指示・質問応答・ライブラリへの質問・質問応答の連続対話・書き起こしの翻訳のすべてがアンロックされ、すでに Pro を購入済みの場合は追加購入なしで使えます。**直接配布版は Pro 機能を無料で開放しています** (直接販売 #172 は見送り中 — MONETIZATION.md §8)
- その他: 録画エンジン (KildeCore) を v0.26.0 に更新 (書き起こしの翻訳のエンジン実装 kilde-cli-swift#149 — `TranscriptTranslator` / `TranslationLanguage` / `ProFeature.translation`。長い文字起こしはチャンクごとに翻訳し、進捗を表示します)。録画の挙動 (収録・文字起こしの実行) に変更はありません
