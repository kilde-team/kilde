# 0.45.0

評価・レビュー獲得導線の強化 (issue #612)。#597 の現状調査で «MAS レビュー 0 件による
社会的証明の欠如» が最重要課題 (優先候補 3) と判明したことを受け、評価依頼の発火
タイミングを成功体験の直後へ寄せ、設定から評価ページへ到達できる常設導線を追加した。
録画・文字起こしの機能変更はありません。

## 評価依頼のタイミングを成功体験の直後へ寄せた

- 以前は «録画の完了直後» だけを判断していたため、文字起こしが始まっていると依頼は
  見送られ、次の録画完了まで持ち越されていた。0.45.0 からは **録画後の文字起こしや
  要約が正常に終わった直後** (transcription.onCompletion) に依頼を試みる —
  «録って文字起こしまで終わった» が依頼に値する瞬間。文字起こしが絡まない録画
  (トグルオフ) は従来どおり録画の完了直後に判断する。ライブラリの «後から文字起こし»
  やファイル取り込みの成功も同じ窓口に入る
- 依頼の規則そのものは変えていない: «15 秒以上の成功した録画の完了 3 回目以降» かつ
  «最低 90 日は再依頼しない» (ReviewPromptPolicy)。窓が無ければ日付を記録せず
  見送る — «窓が無かった» ことを 90 日に束縛しないため (次の成功体験で再試行)。
  規則の単位は «録画の完了» のまま (文字起こしの完了は回数を進めない)
- 頻度制御は StoreKit (AppStore.requestReview) の標準仕様の範囲内 — システム側の
  表示上限にも従う。ダークパターン (閉じにくい表示・評価の強要・特典との引き換え)
  は無い。失敗した文字起こしからは依頼しない («うまくいった» 体験の直後だけ)
- セルフテスト (`KILDE_GUI_SELFTEST_REVIEW=1`) に «文字起こしの完了» の窓口の
  分岐を追加 (規則・状態保持とも)

## 設定に «App Store で評価する» を追加 (常設導線)

- MAS 版の設定 «アプリを応援» に «App Store で評価する» を追加。利用者の
  手動操作で App Store の書き込み画面 (`macappstore://apps.apple.com/app/id6812783176?action=write-review`)
  を直接開く。評価依頼のダイアログは «出るかどうか» が規則と頻度制御で決まるため、
  «今すぐ評価したい» 利用者に確実な口が無かった。チップ (IAP) の商品が読めない
  環境でも出す («いつでも評価できる口» が StoreKit の可用性に依存しないため)
- 直接配布版には出さない — App Store のライブラリに無い利用者がほとんどで、
  そちらの支援口は既存の GitHub Sponsors («アプリを応援») のまま
