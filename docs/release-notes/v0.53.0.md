## この版の内容

リポジトリ側 (docs) のみの変更で、配布物のアプリは 0.52.0 と同じ内容です:

- **2026-11 月次行の整備** (docs/metrics.md / docs/appstore/metadata/metrics.md):
  ASC 週次表に 2026-11 分の表を «取得元 / 集計窓 / 記入先» つきで新設しました。
  GA4 月次台帳と IAP 販売数月次台帳の 2026-11 行は既存のため、値と状態を更新しました
- **取得できた値だけを出典つきで記入**: ASC API の Sales Report から
  2026-11-01〜24 (PT) の初回 DL 代理 (F1) 28 件と kilde.pro 販売 1 件を、
  iTunes Lookup から評価件数の補助値 0 件 (jp / us) を記入しました
- **未取得項目は «未記入 (取得待ち)» と理由つきで明記**: GA4 の指標、ASC 分析の
  ユニーク系指標・初回 DL の正本、評価数の正本はオーナー作業待ちです。推測値は
  書いていません
- **#161 / #174 判定欄の具体化**: 対象期間・判定に必要な母数・判定不可となる条件を
  明記しました。判定は «判定不可» のままです (実測値は 2026-12 月初の振り返りで
  記入します)
- docs/appstore/metadata/metrics.md に 0.52.0 の承認日 (2026-11-26 JST) を記入
- ユーザーに見えるアプリの変更はありません — 0.52.0 の録画・文字起こし・
  要約・Pro 機能 (7 種) はそのままです
