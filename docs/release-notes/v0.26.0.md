# 0.26.0

## 0.26.0 の改善

- **会議の要約が Pro になりました** (issue #169 / #170 — 第一弾 Pro。買い切り ¥2,800、
  サブスクリプションではありません)。録画のあと、要点・決定事項・アクションアイテムを
  自動でまとめ、Markdown の先頭に載せます。処理は Apple Intelligence の**オンデバイス
  処理**で、録音内容が外部に送られることはありません
- **録画と文字起こしは、これまでどおり無料です** — Pro は要約の生成のみの対価で、
  無料機能の体験は一切変わりません。未購入の間は設定パネルの «録画後に要約も作る« が
  ロック表示になり、クリックすると購入導線 (価格・購入・購入の復元) が開きます
- **直接配布 (DMG) 版は Pro も無料のまま使えます** — Pro の直接販売 (issue #172) は
  当面見送りのため、この版では要約も引き続き無料です (App Store 版のみの課金)
- `kilde` コマンドライン (CLI) は全機能が無料のままです (要約を含む — `--summary`)

## 内部の変更

- エンジン (kilde-cli-swift) を **v0.19.0 → v0.20.0** に更新 (kilde-cli-swift#135 —
  要約の Pro ライセンスゲートの接続。判定は private エンジン側で行われ、検証は
  オフライン完結です — 電話ホーム・テレメトリはありません)
- App Store 版の課金は非消耗型 «kilde.pro« (StoreKit 2)。権利の確認は
  `Transaction.currentEntitlements` のみで行います
- Pro のゲートとビルドごとの初期権利はセルフテスト `KILDE_GUI_SELFTEST_PRO` で
  機械検証できます (docs/DEVELOPMENT.md §3)
