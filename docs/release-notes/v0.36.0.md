# 0.36.0

## 録画ライブラリから録画をゴミ箱へ移せるように

- **録画ライブラリで録画を «ゴミ箱に入れられる» ようになりました** (issue #523)。溜まった会議の録画を、«フォルダを開く» で Finder を開かずにライブラリの中で整理できます。一覧の録画を右クリック、または詳細の右上のボタンから実行します (実行前に確認ダイアログが出ます)
- **録画と一緒に、同じ名前の文字起こし・議事録のファイルも移ります** (.json / .md / .txt / .srt / .vtt と枝番) — «録画だけ消えて文字起こしが残る» を避けるためです。ユーザーが同じフォルダに保存した書き出し (同じ名前) も一緒に移ります
- **ほかの録画が持つ文字起こしは残ります** — 同じ名前の録画形式のファイル (たとえば取り込みで名前が重複した `-2.m4a`) が隣にいるとき、その録画のサイドカーは «そちらのもの» として残します。消した録画の代わりに、残った録画が文字起こしを失わないためです
- **«消す» ではなく «ゴミ箱に入れる»** — Finder の «ゴミ箱» から «戻す» で復元できます (誤操作に安全な 2 重の安全装置: 確認ダイアログと復元可能な移動)
- **文字起こしの実行中・待機中の録画と、録画中の録画は移せません** — 処理中・書き込み中のファイルを消さないため、導線が無効になります
- ライブラリの一覧と検索からは、移した録画が消えます。Spotlight への反映は既存の差分同期が行います (同期の実行時に反映されるため、すぐには消えないことがあります)
- ゴミ箱への移動に失敗したときはその旨を表示します (黙って失敗しません)。保存先フォルダが読めなかったときは何も移さずにその旨を案内し、移動自体に失敗したとき (権限の無い保存先・ネットワークボリュームなど) は «Finder で削除してください» の案内が出ます
- 処理の対象は、その録画と同じ名前のファイルだけです。録画の内容が端末の外へ送られることはありません

## その他

- 録画エンジン (KildeCore) の変更はありません (エンジン pin は v0.22.0 のまま)
