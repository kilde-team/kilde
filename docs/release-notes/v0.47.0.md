# 0.47.0

要約の生成に失敗したときの理由表示を整えるエンジン修正 (kilde-cli-swift#154)。
録画・文字起こし・要約の挙動は 0.46.0 から変わりません。

## 要約の失敗理由の表示を整える (kilde-cli-swift#154)

- 文字起こしの要約が生成できなかったとき、GUI の «要約は生成できませんでした (…)»
  の note と CLI の ⚠ 行に載る理由文の改行判定を `isNewline` ベースに変えました
- 以前は `split(separator: "\n")` だったため、CRLF (`\r\n`) 区切りのエラー文
  (Windows 由来のエラーなど) で最初の «1 行» の末尾に `\r` が残り、note の
  1 行契約を崩しうる状態でした。GUI 側の同種修正 (kilde#585) は済んでおり、
  エンジン側だけが残っていたのを今回で揃えました
- CRLF・CR 単体のケースを単体テストに追加して縛っています
