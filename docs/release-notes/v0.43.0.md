# 0.43.0

メタデータのみのリリース (issue #594 — issue #160 変更 5 «App Store 製品ページの
最適化»)。**録画・文字起こしを含め、アプリの機能の変更はありません**。
直接配布版の v0.43.0 タグは 0.42.0 と同じコード (ドキュメントと App Store
メタデータの更新のみ) で、Homebrew 経由でインストール済みの利用者の
アップデートは署名と notarization の更新だけが実質的な内容です。

## App Store 製品ページの説明文を現在の機能セットに更新

- **説明文 (全 5 ロケール) に、0.26.0 以降に追加された機能を追記しました**:
  議事録 (要約)・フォローアップの下書き・質問応答・ライブラリへの質問・
  質問応答の連続対話・書き起こしの翻訳 (いずれも Pro 機能 — Apple Intelligence
  による端末内処理、macOS 26 以降) と、ライブラリまわりの機能 (テキスト /
  Markdown / 字幕 SRT / WebVTT の書き出し、要約のアクションアイテムの
  リマインダー追加、既存ファイルの取り込み、Spotlight 対応)
- **«無料» の範囲を正確にしました**: 旧説明文の «Free, no ads, open source» は
  要約が Pro になった (0.26.0) 以降もそのままだったため、«録画と文字起こしは無料 /
  Pro は買い切り (サブスクリプションではない)» に言い換えました
- **キーワードを見直しました**: en-US は汎用の «video» «mp4» を «speech to text» へ、
  es-ES に «notas» を、ko に «강의» を追加 (いずれも各ロケールの上限 — 100 文字 /
  ja の実績 180 バイト — 以内)。ja と zh-Hans はすでに上限いっぱいで主要語を
  網羅しているため変更なし。**他社商標は使っていません** (#160 のスコープどおり)
- サブタイトルは全ロケール不変 («差別化 + 文字起こし» の現行文面が最適と判断)。
  スクリーンショット (7 枚、0.41.0 で更新) とプレビュー動画 (ja / en-US、0.23.0 で
  登録) も UI に変更が無いため差し替えません
