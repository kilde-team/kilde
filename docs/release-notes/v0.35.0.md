# 0.35.0

## 録画中にディスプレイがスリープしないように

- **映像ありの録画のあいだ、Mac がディスプレイのアイドル スリープに落ちなくなりました** (issue #516)。消灯中は ScreenCaptureKit がフレームを出さないため、離席中にディスプレイが切れると «スリープ中の分の映像が欠ける» (復帰後の自動リスタートで録画は続く) か «中断を使い切って録画が途中で終わる» ことがありました。録画セッションのあいだだけディスプレイのスリープを防ぐ (IOPMAssertion `PreventUserIdleDisplaySleep`) ので、**録画を始めると画面は消えなくなります。停止すると、ふだんのスリープの挙動に戻ります**
- **会議の自動録画で始めた録画でも同じです** — 防止は録画モデル (RecordingController) の開始と終了に結び付けてあるので、パネルから始めた録画でも自動で始めた録画でも効きます
- **音声のみの録音には効かせません** — 消灯の影響は映像フレームに限られるため、録音だけのときの挙動は変わりません
- **ノートパソコンの蓋を閉じたときのスリープ (クラムシェル) は防げません** — 防げるのは «自動でのスリープ» のみです。蓋を閉じる運用での録画は対象外です
- **新しい権限は不要です**。kilde が OS に伝えるのは «このあいだはスリープしないで» という電源管理の指示だけで、端末外へ何かを送る変更はありません
- 取得や解放が OS 側で失敗しても録画は続きます (その旨を記録し、次の録画の開始・停止のときに解放をやり直します)
- 計測イベントは追加していません (利用者の操作を伴わないため)

## その他

- 録画エンジン (KildeCore) の変更はありません (エンジン pin は v0.22.0 のまま)
