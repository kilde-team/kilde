## 0.10.0 の改善

- **既定の録画サイズを 1 時間あたり約 200MB に圧縮**しました (エンジン v0.10.0)。従来の既定では内容によっては 1 時間で 1GB を超えていたため、会議を録りっぱなしで保管するときのディスク容量が大きく節約できます。映像の既定ビットレートを 12 Mbps から 350 kbps へ、音声を 96 kbps に揃え、キーフレーム間隔を 2 秒に固定しました
- 動きの多い画面や細かい文字を鮮明に残したいときは、設定ファイル (`~/.kilde/config.json`) の `videoBitrate` / `audioBitrate` でビットレートを上げることで従来並みの画質にできます
- **CLI**: `--fps` に 1〜240 の範囲チェックを追加しました (範囲外は終了コード 64 で拒否します)。従来は大きな値が黙って受理される場合がありました
