# 0.27.0

## 内部の変更

- **Pro (会議の要約の買い切り) の購入導線と要約機能の利用状況を、集計統計に加えました** (issue #456)。ロックの表示、購入の開始とその結果 (キャンセル・承認待ち・失敗)、権利の付与、購入の復元の失敗、要約の開始・完了・失敗・生成されなかった理由 — それぞれの回数と区分だけを送ります。**価格や金額、購入のトランザクション ID、録画・文字起こし・要約の内容、ファイル名は含まれません** (PRIVACY.md «利用統計» の枠内。App Privacy ラベルも変わりません)
- この集計は、Pro の購入導線でどこで離脱しているかを知り導線を改善するために使います (エピック #174)。Mac App Store 版だけが購入導線の対象で、直接配布版は Pro が無料開放のため要約の利用状況のみが集計されます
- 設定の「アプリの利用統計とクラッシュレポートを送信する」をオフにしているときは、これまでの利用統計と同じく一切送信されません (issue #435)
- 機能の変更はありません。エンジン (kilde-cli-swift) の変更もありません (pin は v0.20.0 のまま)
