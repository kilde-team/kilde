# 0.40.0

## 録った会議の質問応答で、答えを踏まえた追質問ができるように

- **質問応答のシート («質問する» «ライブラリに質問») で、答えを踏まえた追質問ができるようになりました** (issue #556 — 第六弾 Pro、エンジン kilde-cli-swift#147)。«その金額は?» «じゃあ B社の件は?» のように、これまでの質問と答えを文脈に加えて質問すると、前のやり取りを踏まえた答えが返ります (これまでどおり、質問と文字起こしは端末の外へ出ません — Apple Intelligence のオンデバイス処理、macOS 26 以降。Apple Intelligence が使えない環境では «質問する» / «ライブラリに質問» が無効になり、理由がツールチップに表示されます)
- **過去の質問と答えはシートの中に履歴として残ります** — 新しい質問の実行で前の回答を消さずに積み重ね、答えの根拠 («どの行か» «どの会議の、どの行か») も質問ごとに表示します。履歴はシートの寿命で、**シートを閉じると消えます** («最初からやり直す» ときはシートを閉じて開き直します)。失敗した質問は履歴に積まれません (失敗表示はこれまでどおり入力欄の上に出ます)
- **«コピー» は最新の答えと根拠が対象です** — これまでの «回答のコピー» と同じ対象です (履歴全体のコピーは対象外)。«質問し直す» のラベルを廃止し、«答えを得る» に統一しました (前の回答を消して質問し直すのではなく、続けて質問する流れになったため)
- **«ライブラリに質問» の追質問でも、検索欄の語はこれまでどおり録画の優先に使われます** — «検索で絞り込んだうえで質問» を追質問でもそのまま精度に繋げます
- **追質問は Mac App Store 版の kilde Pro (買い切り ¥2,800) に含まれます** (第六弾) — 買い切り 1 商品で要約・フォローアップの下書き・カスタム指示・質問応答・ライブラリへの質問・質問応答の連続対話のすべてがアンロックされ、すでに Pro を購入済みの場合は追加購入なしで使えます。**直接配布版は Pro 機能を無料で開放しています** (直接販売 #172 は見送り中 — MONETIZATION.md §8)。設定パネルの «カスタム指示» は追質問にも反映されます
- その他: 録画エンジン (KildeCore) を v0.25.0 に更新 (質問応答の連続対話のエンジン実装 kilde-cli-swift#147 — 履歴の正規化と文字数予算への収めはエンジン側が担います)。録画の挙動 (収録・文字起こしの実行) に変更はありません
