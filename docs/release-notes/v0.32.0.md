# 0.32.0

## 文字起こしの持ち出しの改善 (録画ライブラリ)

- **文字起こしを字幕形式 (SRT / WebVTT) に書き出せるようになりました** (issue #493)。ライブラリの «書き出す» メニューで、プレーンテキスト (.txt) のほかに SubRip 字幕 (.srt) と WebVTT 字幕 (.vtt) を選べます (動画投稿などで字幕が要るときにそのまま使えます)。書き出しの中身は «録画後に文字起こし» がサイドカーを書くときと同じ整形器 (エンジンの TranscriptFormatter) が作るため、出力はサイドカーと同じ形式の契約に従います
- **文字起こしをワンクリックでコピーできるようになりました**。«全文をコピー» で文字起こし全体を «[時刻] 本文» の形でクリップボードへ入れ、セグメント行の右クリック («このセグメントをコピー») ではその行の本文だけをコピーします (行は «クリックでシーク» のボタンのため、これまでは本文をテキスト選択できませんでした)
- テキスト / Markdown 形式で保存した文字起こしには終了時刻が記録されないため、そこから書き出した字幕の cue の終了時刻は概算になります (終了時刻 = 次のセグメントの開始。最後のセグメントは開始と同じ)。書き出しはサイドカーの情報以上を推測しません
- 計測: «どの形式で書き出されたか» (`transcript_export`) と «コピーの単位» (`transcript_copy`) の利用統計イベントを追加しました (区分値のみ — PRIVACY.md «利用統計» の枠内。オプトアウトの設定はそのまま効きます)

## その他

- 録画エンジン (KildeCore) の変更はありません (エンジン pin は v0.22.0 のまま)
