## 0.20.0 の改善

- **会議の自動録画で、カレンダーの予定名を録画ファイル名に使えるようになりました** (issue #393)。設定の «カレンダーの予定名を録画ファイル名に使う» をオンにすると (既定はオフ)、検知した会議と時間帯が重なるカレンダーの予定の題名を、録画ファイル名 (`kilde-<日時>-<予定名>`)・録画開始通知・議事録の見出しに使います
- カレンダーはこの機能のために読み取りだけに使われ、カレンダーの内容がネットワークに送信されることはありません。予定の作成・変更・招待は行いません ([PRIVACY.md](https://github.com/kilde-team/kilde/blob/main/PRIVACY.md))
- カレンダーの権限を拒否したとき・該当する予定が無いとき・検索が間に合わなかったときは、録画は従来どおりの既定名で行われます (文字起こしは録画とは独立した既存の設定で、この変更の影響を受けません)
