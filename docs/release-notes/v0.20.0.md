## 0.20.0 の改善

- **会議の自動録画で、カレンダーの予定名を録画ファイル名に使えるようになりました** (issue #393)。設定の «カレンダーの予定名を録画ファイル名に使う» をオンにすると (既定はオフ)、検知した会議と時間帯が重なるカレンダーの予定の題名を、録画ファイル名 (`kilde-<日時>-<予定名>`)・録画開始通知・議事録の見出しに使います
- カレンダーはこの機能のために読み取りだけに使われ、内容がネットワークに送信されることはありません。予定の作成・変更・招待は行いません (PRIVACY.md)
- カレンダーの権限を拒否したとき・該当する予定が無いとき・検索が間に合わなかったときは、従来どおりの既定名で自動録画・文字起こしが動きます
