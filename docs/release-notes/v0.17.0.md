## 0.17.0 の改善

- **収録対象 (画面 / 音声のみ) の既定値を、CLI と共有する設定ファイル (config.json) に保存するようにしました** (issue #372)。0.16.x までは GUI 内部の設定に保存していた «ディスプレイ»・«音声のみ» の選択を、録画設定ファイルの `defaultTarget` キー (エンジン kilde-cli-swift v0.17.0 — kilde-cli-swift#123) に保存します。保存は**録画開始時** («この音声・保存先の選択を既定にする» ボタンでも) に行われ、`kilde config show` でも確認できます
- 0.16.x までに選んでいた収録対象は、初回起動時に設定ファイルへ自動的に取り込まれます (手動の操作は不要です)
- **ウィンドウの選択は設定ファイルに保存されません** — windowID はアプリの起動ごとに振り直される一時的な ID のためです。これまでどおりアプリ内に保存し、復元時にウィンドウの存続と所有アプリの一致を確かめてから採用します
- 録画エンジンを kilde-cli-swift **v0.17.0** に更新しました (収録対象の設定キーの追加のみで、録画の挙動は不変です)
