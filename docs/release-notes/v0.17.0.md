## 0.17.0 の改善

- **収録対象 (画面 / 音声のみ) の既定値の保存先を、設定ファイル (config.json) の `defaultTarget` キーにまとめました** (issue #372)。0.16.x までは GUI 内部の設定に保存していた «ディスプレイ»・«音声のみ» の選択を、エンジン kilde-cli-swift v0.17.0 (kilde-cli-swift#123) が追加したキーに保存します。保存は**パネルからの録画開始時** (開始ボタン・グローバルホットキー。ショートカットや会議の自動録画の開始では保存されません) に行われ、«この音声・保存先の選択を既定にする» ボタンでも保存されます
- **直接配布 (DMG) 版**では設定ファイルを CLI と共有するため、選択した収録対象が `kilde config show` でも確認できます。**App Store 版**では設定ファイルはアプリのコンテナ内にあり CLI とは共有されません (保存の挙動はどちらの版も同じです)
- 0.16.x までに選んでいた収録対象は、初回起動時に設定ファイルへ自動的に取り込まれます (手動の操作は不要です)
- **ウィンドウの選択は設定ファイルに保存されません** — windowID はアプリの起動ごとに振り直される一時的な ID のためです。これまでどおりアプリ内に保存し、復元時にウィンドウの存続と所有アプリの一致を確かめてから採用します
- 録画エンジンを kilde-cli-swift **v0.17.0** に更新しました (収録対象の設定キーの追加のみで、録画の挙動は不変です)
