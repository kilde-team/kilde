# 0.34.0

## 議事録の要約から、アクションアイテムをリマインダーへ

- **要約つきの議事録から、要約のアクションアイテムをリマインダー (Reminders.app) に追加できるようになりました** (issue #509)。ライブラリで録画を選ぶと «リマインダーへ追加» ボタンが出ます。押すと、要約のアクションアイテムが **リマインダーの既定のリスト** に追加されます (kilde 専用のリストは作りません — «やること» を普段使うタスク管理に流すため)
- **どの会議のアクションかは、項目のメモ欄に «kilde — <録画名>» の形で残ります** — リマインダー側で出所を追跡できます。**同じ議事録でもう一度押すと、同じ項目が重複して追加されます** (追加の重複防止はしていないため。取り消しはリマインダー側で消す運用です)
- **初回に押したときだけ、リマインダーへのアクセスを求めます**。拒否した場合は、ボタンの横に «リマインダーの設定を開く» の案内が出ます
- **kilde がリマインダーに対して行うのは項目の追加だけです** — 既存の項目の読み取り・変更・削除はしません。追加する内容はこの Mac の中で組み立てられ、kilde が外部へ送信することはありません (PRIVACY.md «リマインダー»。既定のリストが iCloud のリマインダーの場合、ほかの端末への反映は macOS 側の同期で行われます — kilde の通信ではありません)
- ボタンが押せるのは **要約のアクションアイテムがある議事録** のときです。要約がない・アクションアイテムがない議事録では、理由をツールチップで案内します
- «リマインダーへ追加» は Pro ではありません — 要約の «生成» は Pro の機能ですが、出来上がった議事録 (.md) の持ち出しはこれまでどおり無料です («書き出し先の連携» と同じ位置づけ)
- 計測: «リマインダーへ書き出した回数» (`reminder_export`) の利用統計イベントを追加しました (パラメータなし — docs/metrics.md «送っているイベント» と同じ語彙。PRIVACY.md «利用統計» の枠内。項目の文面・件数・どの録画からかは送りません。オプトアウトの設定はそのまま効きます)

## その他

- 録画エンジン (KildeCore) の変更はありません (エンジン pin は v0.22.0 のまま)
