# 0.28.0

## Pro 機能の追加

- **フォローアップの下書き (第二弾 Pro) を追加しました** (issue #464)。ライブラリで議事録 (.md) を持つ録画の «フォローアップを下書き» から、要約 (要点・決定事項・アクションアイテム) を元に参加者へ送るメッセージの下書きを生成できます。形式はメール (件名 + 本文) とチャットの 2 種類で、生成後にそのままコピーできます。処理は Apple Intelligence のオンデバイス処理で、入力が外部に送られることはありません (macOS 26 以降)
- **kilde Pro (買い切り ¥2,800) に含まれます** — 追加の購入は不要で、すでに Pro を購入済みの場合はそのまま使えます。録画と文字起こしは無料のままです
- Pro 未購入では «フォローアップを下書き» はロックされ、設定パネルの購入導線から購入できます (購入導線はこれまでの «控えめ» 方針のままです)

## 内部の変更

- フォローアップの下書きの利用状況 (開始・完了・失敗の回数と処理時間・失敗種別の区分) を集計統計に加えました (issue #464)。**生成した下書きの内容は送信しません** (PRIVACY.md «利用統計» の枠内。App Privacy ラベルは変わりません)。設定の «アプリの利用統計とクラッシュレポートを送信する» がオフのときは一切送信されません
- 購入導線の文面を «会議の要約とフォローアップをアンロック» に更新しました (Pro の内容が 2 機能になったため)
- エンジンを kilde-cli-swift **v0.21.0** に更新しました (FollowupComposer・`ProFeature.followupDraft`・議事録 .md からの要約の復元 — kilde-cli-swift#137)
