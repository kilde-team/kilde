# 0.29.0

## Pro 機能の追加

- **カスタム指示 (第三弾 Pro) を追加しました** (issue #472)。設定パネルで指定した内容 (トーン・宛先・署名・強調してほしいポイント・自由記述の指示) が、会議の要約とフォローアップの下書きの生成に反映されます。処理は Apple Intelligence のオンデバイス処理で、入力が外部に送られることはありません (macOS 26 以降)
- **Mac App Store 版の kilde Pro (買い切り ¥2,800) に含まれます** — 追加の購入は不要で、すでに Pro を購入済みの場合はそのまま使えます。録画と文字起こしは、現在無料です
- Mac App Store 版で Pro 未購入のときはカスタム指示のセクションはロックされ、設定パネルの購入導線から購入できます (購入導線はこれまでの «控えめ» 方針のまま)。**直接配布版は Pro 機能を無料で開放しています** (直接販売 #172 は見送り中 — MONETIZATION.md §8)

## 内部の変更

- エンジンを kilde-cli-swift **v0.22.0** に更新しました (ComposerInstructions・`ProFeature.customInstructions` — summarize / compose の 2 段目のゲート。kilde-cli-swift#139)
