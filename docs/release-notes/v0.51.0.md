# 0.51.0

メンテナンスリリース。**録画・文字起こしなどアプリ本体の挙動は変わりません。**
0.50.0 と比べたアプリの変更はありません (エンジン pin も v0.28.0 のまま)。
この版の変更はリポジトリ内の計測台帳の整備です (kilde#635、エピック kilde#174 関連)。

## この版の内容

リポジトリ側 (docs) のみの変更で、配布物のアプリは 0.50.0 と同じ内容です:

- **IAP 販売数の月次台帳の整備** (docs/metrics.md «IAP 販売数と DL の月次台帳»):
  台帳に «記入日»・«チップ販売の SKU 別内訳 (small / medium / large)»・
  «売上 (Developer Proceeds、通貨別)» の列を追加し、転記手順
  (取得元 / 集計窓 / 記入日 / 母数が小さいときの読み方) を明文化しました
- **#174 出口条件 («有料転換 2%») の判定欄を新設**: 母数 < 100 のうちは
  «判定不可» とする読み方 (率は Pro 販売開始日からの pooled 累計比を参考併記) を
  定め、現時点の判定を «判定不可 (母数不足)» と根拠 (最新の MAS 初回 DL 母数:
  代理指標 F1 18 件 / 2026-11-01〜17) つきで記入しました
- 2026-11 の台帳行に既知の実績を出典つきで転記 (kilde.pro 1 件 / USD 15.29、
  F1 18 件 — ASC Sales Report 実測 2026-11-19、issue #598)。ASC 分析の
  «初回ダウンロード» (判定の正本分母) は CSV エクスポートを要するため
  «未記入 (ASC 転記待ち)» と明記
- ユーザーに見えるアプリの変更はありません — 0.50.0 の録画・文字起こし・
  要約・Pro 機能 (7 種) はそのままです
