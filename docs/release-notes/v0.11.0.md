## 0.11.0 の改善

- **録画ライブラリから文字起こしをテキストファイル (.txt) に書き出せる**ようになりました (issue #329)。詳細ペインの «テキストに書き出す» で保存先を選ぶと、表示中の文字起こし全体を «[HH:MM:SS] 本文» の 1 行 = 1 セグメントのテキストで保存します。サイドカーの形式 (json / srt / vtt / txt / md) に関わらず同じテキスト形式で書き出され、検索で絞り込んでいても録画全体が対象です
- 前回の DMG (v0.10.0) には間に合わなかった **ライブラリからの «後から文字起こし・議事録を作成»** (issue #321) も含みます。文字起こしをオフで録った録画をライブラリで選び、その場で文字起こしを作成できます (文字起こしには macOS 26 以降、議事録の要約には Apple Intelligence が必要です)
