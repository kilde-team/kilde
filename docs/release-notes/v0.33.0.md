# 0.33.0

## 録画を Spotlight から探せる (録画ライブラリ)

- **録画を Spotlight で探せるようになりました** (issue #502)。ライブラリにある録画の名前・録画日時・長さに加えて、**文字起こししたテキストの中身でも** Spotlight 検索にヒットします («あの件、どの会議で話したか» を Spotlight の検索欄から直接探せます)
- **Spotlight の結果を選ぶと録画ライブラリが開き、その録画が選択された状態で表示されます** (アプリが起動していないときは起動して開きます)
- 索引は差分で更新されます — 録画や文字起こしを消したら、次の走査 (アプリ起動・ライブラリを開く・文字起こしの完了) で Spotlight からも消えます
- **索引はこの Mac の中にだけ保存され、外部には送りません** (PRIVACY.md «Spotlight 索引»)。設定ウィンドウの «録画ライブラリ» にある «録画と文字起こしを Spotlight に登録する» をオフにすると、索引はすぐに消去されます。既定はオンです
- 計測: «Spotlight から開いた回数» (`spotlight_open`) の利用統計イベントを追加しました (区分値のみ — PRIVACY.md «利用統計» の枠内。どの録画を開いたかは送りません。オプトアウトの設定はそのまま効きます)
- 設定ウィンドウの «録画ライブラリ» セクションの新規文字列 (en / es / ko / zh-Hans) を Localizable.xcstrings に追加しました

## その他

- 録画エンジン (KildeCore) の変更はありません (エンジン pin は v0.22.0 のまま)
