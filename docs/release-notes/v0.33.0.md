# 0.33.0

## 録画を Spotlight から探せる (録画ライブラリ)

- **録画を Spotlight で探せるようになりました** (issue #502)。ライブラリにある録画の名前・録画日時・長さに加えて、**文字起こししたテキストの中身でも** Spotlight 検索にヒットします («あの件、どの会議で話したか» を Spotlight の検索欄から直接探せます)。**文字起こしは先頭 10 万字までが検索対象です** (長さの属性は文字起こしのある録画に付きます) (それより長い文字起こしでは、後半の語句は Spotlight の検索対象になりません。アプリ内のライブラリの全文検索は全文が対象です)
- **Spotlight の結果を選ぶと録画ライブラリが開き、その録画が選択された状態で表示されます** (アプリが起動していないときは起動して開きます。**現在の保存先にある録画が対象** — 以前の保存先の録画はライブラリが開くだけで選択されません)
- 索引は差分で更新されます — 録画や文字起こしを消したら、次の走査 (アプリ起動・ライブラリを開く・文字起こしの完了) で Spotlight からも消えます
- **Spotlight に登録する内容はこの Mac の中にだけ保存され、kilde が外部へ送信することはありません** (Spotlight 検索機能自体の通信には踏み込まない — PRIVACY.md «Spotlight 索引»)。設定ウィンドウの «録画ライブラリ» にある «録画と文字起こしを Spotlight に登録する» をオフにすると、索引は消去されます。既定はオンです。消去はベストエフォートで、万一失敗したらログに記録し、オンに戻したときの差分同期で実在しない録画を取り除きます
- 計測: «Spotlight から開いた回数» (`spotlight_open`) の利用統計イベントを追加しました (パラメータなし — docs/metrics.md «送っているイベント» と同じ語彙。PRIVACY.md «利用統計» の枠内。どの録画を開いたかは送りません。オプトアウトの設定はそのまま効きます)
- 設定ウィンドウの «録画ライブラリ» セクションの新規文字列 (en / es / ko / zh-Hans) を Localizable.xcstrings に追加しました

## その他

- Spotlight 索引のアイテムには有効期限を明示的に «無期限» に設定しました — システムの既定は約 1 か月の有効期限 (SDK ヘッダの記載) で、放置すると «1 か月後に録画が Spotlight から消える» ためです
- 録画エンジン (KildeCore) の変更はありません (エンジン pin は v0.22.0 のまま)
