# 0.48.0

メンテナンスリリース。録画・文字起こし・要約の**生成処理と挙動は 0.47.0 から
変わりません** (エンジンのコメントの機序説明の整理と、リリース基盤の観測性改善のみ)。

## この版の内容

- 録画・文字起こし・要約・Pro 機能の挙動変更はありません
- エンジン (kilde-cli-swift) の `summaryFailureReason(of:)` まわりの**コメントの
  機序説明**を、実際の split の挙動 («split できず全体が残る») に合わせて書き換えました
  (kilde-cli-swift#156)。挙動・テスト・DESIGN.md は不変です
- MAS 提出経路 (`mas.yml`) の停滞検知の watchdog に、打ち切り時の**最終ログ位置・
  段階の記録と診断出力** (経過・無出力時間に加えて停滞箇所の推定と、ランナーの
  キーチェーン状態などの事後調査用の出力) を追加しました (issue #470 の残件の
  調査のための観測性改善)。アプリ本体には影響しません

## エンジン (kilde-cli-swift)

- **v0.27.1 → v0.27.2** — コメントの機序説明の整理のみ (kilde-cli-swift#156)。
  `gui/project.yml` の `exactVersion` と `release.yml` の `ref` を同一 PR で
  揃えて更新しています
