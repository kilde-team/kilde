## 描述

```text
kilde 是一款开源的 macOS 屏幕与音频录制工具，能把系统自带的屏幕录制
无法捕捉的“系统声音”一起录下来，一键即可完成。

为会议而生
录制线上会议时，把对方的声音（系统声音）和你的声音（麦克风）
混合进同一个文件。选择窗口后只录该应用的音频，
通知提示音和其他应用的声音都不会混入。各音频来源分轨录制时，
转写会带上说话人标签（自己 / 对方）。还可以在检测到会议窗口时
自动开始录制（默认关闭）。

录制后转写并摘要（macOS 26 及以上）
录制结束后，转写完全在本机上处理，并以 Markdown 文件写在录像
旁边。在启用了 Apple Intelligence 的机型上还能生成会议摘要。
音频和转写内容不会发送到任何地方。

全文搜索，直达关键时刻
转写内容可在录像资料库中全文搜索，并从命中的时刻直接开始播放，
不用在几小时的录像里来回拖动进度条。

主要功能
·零配置即可录制屏幕 + 系统声音（原生 ScreenCaptureKit）
·同时录制麦克风或音频接口等输入设备（可混音或分轨）
·按窗口录制 — 音频也限定在该应用
·仅录音频（M4A），无需额外驱动
·可通过全局快捷键或快捷指令开始和停止录制
·无论是停止录制还是退出应用，文件都会完整写入

隐私
录像和转写内容只保存在你的 Mac 上。开发者只会收到启动次数等
汇总的使用统计，以及应用崩溃时的崩溃报告，录像内容和文件本身
绝不会上传。详见 github.com/kilde-team/kilde 的 PRIVACY.md。

运行环境
macOS 14 或更高版本（Apple Silicon）；转写与摘要需要 macOS 26
或更高版本。免费、无广告、开源（MIT）。

本应用与 `kilde` 命令行工具共享同一录制引擎。
详情见 https://github.com/kilde-team/kilde
```

## 新功能 (0.21.0)

转写语言自动检测 (issue #409，引擎 kilde-cli-swift#131 — 设计见 cli-swift
SPIKE-NOTES F-Q)。转写设置的 «语言» 新增 «自动（从录音检测）» (默认仍为

试转写，选取置信度加权平均最高的语言。分轨录制的会议中 «对方的轨道 = 会议语言、

语言模型会从 Apple 下载，与固定语言时相同)。

```text
转写语言设置新增“自动（从录音检测）”。从录音开头的 30 秒检测会议语言（候选：设备语言、日语、英语）并以此转写；分轨录制时，对方轨道和自己的麦克风轨道会分别以各自的语言转写。无法判定时仍使用设备语言。转写需要先启用“录屏后转写”设置，并需要 macOS 26 或更高版本以及相应语言的语音数据（语言模型）（默认设置不变；录音和转写内容不会通过网络发送，但缺失的语言模型会从 Apple 下载；与一般网络请求相同，下载时 IP 地址会送达 Apple）。
```

没有任何付费项目)。

资料库现在可以导入现有的音频/视频文件（MOV、MP4、M4V、M4A、MP3、WAV、AIF、AIFF、CAF、AAC）。选择文件或将其拖放到资料库窗口，在开始使用 kilde 之前或用其他工具录制的会议就会被复制到输出目录，并在设备上进行转写（原文件保持不变；文件名和大小与已有导入相同的文件不会重复复制）。导入的录制内容可以在资料库中搜索。导入和转写需要 macOS 26 或更高版本以及对应语言的语音数据。同时修复：录制结束后菜单栏面板的高度可能仍停留在录制中的紧凑高度的问题。

「发送应用使用统计和崩溃报告」会**立即**停止 Firebase Analytics / Crashlytics 并删除
未发送的崩溃报告。以关闭状态启动时不会调用 `FirebaseApp.configure()`。**默认开启**
(收集内容不变 — 变化的是「可以停止」)。引擎无变化 (pin v0.19.0)。计量对象
(描述 / 关键词 / 副标题 / 截图) 不变。

```text
新增「隐私」设置。取消勾选「发送应用使用统计和崩溃报告」后，会立即停止发送用于改进应用的使用统计和用于修复问题的崩溃报告，并删除 Mac 上尚未发送的崩溃报告。以关闭状态启动时，应用不会初始化分析 SDK。默认开启，收集内容与之前相同；无论如何设置，您的录制、转写内容和文件名都不会被发送。
```
