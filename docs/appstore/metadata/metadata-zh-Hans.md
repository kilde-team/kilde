## 描述

```text
kilde 是一款开源的 macOS 屏幕与音频录制工具，能把系统自带的屏幕录制
无法捕捉的“系统声音”一起录下来，一键即可完成。

为会议而生
录制线上会议时，把对方的声音（系统声音）和你的声音（麦克风）
混合进同一个文件。选择窗口后只录该应用的音频，
通知提示音和其他应用的声音都不会混入。各音频来源分轨录制时，
转写会带上说话人标签（自己 / 对方）。还可以在检测到会议窗口时
自动开始录制（默认关闭）。

录制后转写并摘要（macOS 26 及以上）
录制结束后，转写完全在本机上处理，并以 Markdown 文件写在录像
旁边。在启用了 Apple Intelligence 的机型上还能生成会议摘要。
音频和转写内容不会发送到任何地方。

全文搜索，直达关键时刻
转写内容可在录像资料库中全文搜索，并从命中的时刻直接开始播放，
不用在几小时的录像里来回拖动进度条。

主要功能
·零配置即可录制屏幕 + 系统声音（原生 ScreenCaptureKit）
·同时录制麦克风或音频接口等输入设备（可混音或分轨）
·按窗口录制 — 音频也限定在该应用
·仅录音频（M4A），无需额外驱动
·可通过全局快捷键或快捷指令开始和停止录制
·无论是停止录制还是退出应用，文件都会完整写入

隐私
录像和转写内容只保存在你的 Mac 上。开发者只会收到启动次数等
汇总的使用统计，以及应用崩溃时的崩溃报告，录像内容和文件本身
绝不会上传。详见 github.com/kilde-team/kilde 的 PRIVACY.md。

运行环境
macOS 14 或更高版本（Apple Silicon）；转写与摘要需要 macOS 26
或更高版本。免费、无广告、开源（MIT）。

本应用与 `kilde` 命令行工具共享同一录制引擎。
详情见 https://github.com/kilde-team/kilde
```
