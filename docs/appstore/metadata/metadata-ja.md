## サブタイトル (≤30)

```
QuickTimeでは録れない音まで録れる
```

## 説明

```
kilde は画面と音声を一緒に録画・録音する、macOS 用のオープンソースツールです。
QuickTime Player の画面収録では録れない「システム音声」まで、ワンクリックで録れます。

【会議録画に】
Zoom / Google Meet / Teams の会議を、相手の声 (システム音声) と自分の声 (マイク) を
1 本のファイルにミックスして録画。ウィンドウを選べば、そのアプリの音声だけを録り、
通知音など他のアプリの音は入りません。

【主な特徴】
・画面 + システム音声を追加設定なしで録画 (ScreenCaptureKit ネイティブ)
・マイクや BlackHole などの入力デバイスを同時録音 (ミックス / トラック分離)
・ウィンドウ単位の収録 — 音声もそのアプリにスコープ
・音声のみの録音 (M4A) — ドライバ追加は不要
・録音しながら同じ音を聞ける monitor モード (BlackHole 併用)
・HDR 収録 (macOS 15+, HEVC Main10)
・録画の停止・アプリの終了のどちらでも、ファイルは必ず最後まで書き込まれます

【プライバシー】
録画の内容はあなたの Mac の中だけ。開発者に送信されるのは、起動回数などの
集計された利用統計のみで、録画の内容やファイルが送られることはありません。
詳細はプライバシーポリシー (github.com/kilde-team/kilde の PRIVACY.md) をご覧ください。

【動作環境】
macOS 14 以降 (Apple Silicon)。無料・広告なし・オープンソース (MIT)。

CLI の `kilde` コマンドと同じ録画エンジンを共有しています。詳細は
https://github.com/kilde-team/kilde
```
