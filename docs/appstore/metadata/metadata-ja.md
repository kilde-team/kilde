## 説明

```text
kilde は、Mac の画面とシステム音声をまとめて記録するメニューバー常駐のレコーダーです。標準の画面収録では取り込めないアプリの音や通話相手の声を、自分のマイクと一緒に 1 本のファイルへ収録できます。仮想オーディオドライバなどの追加インストールは必要ありません。

■ 会議を録って、そのまま議事録へ
オンライン会議を、相手の声（システム音声）と自分の声（マイク）の両方を 1 本に混ぜて録れます。音声ソースを「ソースごとに分離」で録ると、文字起こしに話者ラベル（自分 / 相手）が付きます。会議を検知したら自動で録画を始めるオプションもあります（既定ではオフです）。

■ 録画後の文字起こしと要約（macOS 26 以降）
録画が終わると、この Mac の中だけで処理される文字起こしを、録画ファイルの隣に Markdown で書き出します。要約にも対応します（Apple Intelligence が有効な環境が必要）。音声や書き起こした内容が外部へ送られることはありません。

■ 録画ライブラリと全文検索
書き起こした内容はライブラリで全文検索できます。検索語が見つかった時刻からすぐ再生を始められるので、長い録画から必要な場面を探す手間が省けます。

■ 3 つの収録モード
・画面：ディスプレイ全体を収録します。接続中の複数のディスプレイから選べます。
・ウィンドウ：選んだウィンドウだけを収録します。システム音声もそのアプリの音だけに絞られるため、デスクトップ全体を映さずに共有できます。
・音声のみ：映像を録らず M4A で保存します。打ち合わせの記録や文字起こしの用途に適しています。

■ 音声ソースを自由に組み合わせ
システム音声、既定のマイク、接続中のオーディオインターフェースなどを個別に選んで収録できます。複数のソースを 1 トラックに合成するか、ソースごとに分離して書き出すかを切り替えられるので、編集時に自分の声とアプリの音を別々に扱えます。

■ 録画中もメニューバーだけで完結
経過時間はメニューバーに常時表示されます。ポップオーバーではファイルサイズとソース別の入力レベルメーターを確認できるので、マイクが入っていないまま録り続ける事故を防げます。パネルを閉じても録画は続き、グローバルホットキーやショートカットアプリから開始・停止できます。

■ 壊れたファイルを残さない
停止したときはもちろん、アプリを終了したときやアップデートによる再起動時も、書き込み中のファイルを必ずファイナライズしてから終了します。収録し終えたファイルは「最近の録画」から Finder ですぐに開けます。

■ そのほか
・保存先フォルダを自由に指定できます
・ログイン時の自動起動に対応しています
・オープンソース（MIT ライセンス）です。録画の内容や設定を外部へ送信することはありません（アプリの改善のため、Firebase Analytics で匿名の利用統計を、Firebase Crashlytics でクラッシュレポートを収集します）

kilde は macOS 14 以降に対応し、ScreenCaptureKit によるネイティブな収録を行います。文字起こしと要約には macOS 26 以降が必要です。

※ 収録には画面収録の許可が、マイクを使う場合はマイクの許可が必要です。会議や通話を記録する際は、参加者の同意を得たうえでご利用ください。
```

## 新着情報 (0.21.0)

文字起こし言語の自動判定 (issue #409、エンジン kilde-cli-swift#131 — 設計は
cli-swift SPIKE-NOTES F-Q)。設定の文字起こし «言語« に «自動 (録音から判定)« を追加
(既定は従来どおり «端末の言語設定« のまま — 判定の不確実性を既定にしない)。
選ぶと録音ファイルの**音声トラックごと**に冒頭 30 秒を候補ロケール
(端末の言語 + 日本語 + 英語) で書き起こし、時間加重平均 confidence が最大の
ロケールを主ロケールとして選ぶ (誤ロケールの確定結果は低 confidence になる
実測に基づく)。separate 2 トラックでは «相手のトラック = 会議の言語、
自分のトラック = 自分の言語» が別々に決まる。判定不能 (冒頭に発話なし・上位同着)
のトラックは端末の言語設定にフォールバックする (確信を持って誤判定した場合は
そのロケールで書き起こされる — 判定の前提は«候補の中から»である点に注意)。
新しい権限は不要。録音・書き起こしの内容は端末外へ出ない (言語モデルが未取得の
場合は Apple からの取得が発生する — 固定言語の既存挙動と同じ)。

```text
文字起こしの言語設定に「自動 (録音から判定)」を追加しました。録音の冒頭 30 秒から会議の言語を判定して書き起こします (候補は端末の言語・日本語・英語。音声トラックを分けて録った会議では、相手のトラックと自分のマイクのトラックをそれぞれの言語で書き起こします)。判定できなかったときは従来どおり端末の言語設定を使います。文字起こしには「録画後に文字起こし」の設定の有効化と、macOS 26 以降および対象言語の音声データ (言語モデル) が必要です (初期設定は変わりません。録音や書き起こしの内容がネットワークに送信されることはありませんが、言語モデルが未取得の場合は Apple からダウンロードされます。モデル取得の際は一般的な通信と同じく IP アドレスが Apple に伝わります)。
```


## 新着情報 (0.22.0)
既存ファイルの取り込み (issue #416)。ライブラリウィンドウの «ファイルを取り込む…»
(複数選択可) とウィンドウへのドロップで、kilde が録っていない音声・動画ファイルを
文字起こし対象にできる (CLI の `kilde transcribe` にあった経路の GUI 版。**文字起こし
は無料機能のまま**)。**コピーで保存先に持ち込む** — MAS サンドボックスではユーザーが
選んだ任意のファイルの «隣» にサイドカーを書けないため、`kilde-<日時>-<元のファイル名>`
として保存先にコピーしてから既存の文字起こしキューへ投入する (言語・書式は
**取り込みの開始時点で固定** — コピー中に設定を変えても取り込んだ分には影響
しない。要約は付けない)。同じ題名・同サイズのファイルは «取り込み済み» と
みなして重複コピーを作らない (名前と容量による判定で、厳密な同一性保証では
ない)。新しい権限は不要。
録画・文字起こしの機能は従来どおり無料 (0.18.0 のチップ以外に課金は無い)。

```text
ライブラリに「ファイルを取り込む」を追加しました。他のツールで録った会議など、対応する音声・動画ファイル (MOV / MP4 / M4V / M4A / MP3 / WAV / AIF / AIFF / CAF / AAC) を、選ぶかウィンドウにドロップするだけで、保存先にコピーして端末内で文字起こします (元のファイルはそのままです。ファイル名と容量が同じ既存の取り込みは重複コピーしません)。取り込んだ録画はライブラリの検索対象になります。取り込みと文字起こしには macOS 26 以降と、対応する言語の音声データが必要です。あわせて、録画終了後にメニューバーのパネルの高さが録画中の表示のまま戻らないことがある問題を修正しました。
```

## 新着情報 (0.24.0)

利用統計・クラッシュレポートのオプトアウト (issue #435)。パネルの設定に «プライバシー»
セクションを追加し、«アプリの利用統計とクラッシュレポートを送信する» をオフにすると

docs/launch/faq.md §2 «Can I turn it off?» に «Yes» と答えるための版。
エンジンの変更は無し (pin v0.19.0)。計測対象 (説明・キーワード・サブタイトル・スクショ) は不変。

```text

```
