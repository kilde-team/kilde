## 説明

```text
kilde は、Mac の画面とシステム音声をまとめて記録するメニューバー常駐のレコーダーです。標準の画面収録では取り込めないアプリの音や通話相手の声を、自分のマイクと一緒に 1 本のファイルへ収録できます。仮想オーディオドライバなどの追加インストールは必要ありません。

■ 会議を録って、そのまま議事録へ
オンライン会議を、相手の声（システム音声）と自分の声（マイク）の両方を 1 本に混ぜて録れます。音声ソースを「ソースごとに分離」で録ると、文字起こしに話者ラベル（自分 / 相手）が付きます。会議を検知したら自動で録画を始めるオプションもあります（既定ではオフです）。

■ 録画後の文字起こしと要約（macOS 26 以降）
録画が終わると、この Mac の中だけで処理される文字起こしを、録画ファイルの隣に Markdown で書き出します。要約にも対応します（Apple Intelligence が有効な環境が必要）。音声や書き起こした内容が外部へ送られることはありません。

■ 録画ライブラリと全文検索
書き起こした内容はライブラリで全文検索できます。検索語が見つかった時刻からすぐ再生を始められるので、長い録画から必要な場面を探す手間が省けます。

■ 3 つの収録モード
・画面：ディスプレイ全体を収録します。接続中の複数のディスプレイから選べます。
・ウィンドウ：選んだウィンドウだけを収録します。システム音声もそのアプリの音だけに絞られるため、デスクトップ全体を映さずに共有できます。
・音声のみ：映像を録らず M4A で保存します。打ち合わせの記録や文字起こしの用途に適しています。

■ 音声ソースを自由に組み合わせ
システム音声、既定のマイク、接続中のオーディオインターフェースなどを個別に選んで収録できます。複数のソースを 1 トラックに合成するか、ソースごとに分離して書き出すかを切り替えられるので、編集時に自分の声とアプリの音を別々に扱えます。

■ 録画中もメニューバーだけで完結
経過時間はメニューバーに常時表示されます。ポップオーバーではファイルサイズとソース別の入力レベルメーターを確認できるので、マイクが入っていないまま録り続ける事故を防げます。パネルを閉じても録画は続き、グローバルホットキーやショートカットアプリから開始・停止できます。

■ 壊れたファイルを残さない
停止したときはもちろん、アプリを終了したときやアップデートによる再起動時も、書き込み中のファイルを必ずファイナライズしてから終了します。収録し終えたファイルは「最近の録画」から Finder ですぐに開けます。

■ そのほか
・保存先フォルダを自由に指定できます
・ログイン時の自動起動に対応しています
・オープンソース（MIT ライセンス）です。録画の内容や設定を外部へ送信することはありません（アプリの改善のため、Firebase Analytics で匿名の利用統計を、Firebase Crashlytics でクラッシュレポートを収集します）

kilde は macOS 14 以降に対応し、ScreenCaptureKit によるネイティブな収録を行います。文字起こしと要約には macOS 26 以降が必要です。

※ 収録には画面収録の許可が、マイクを使う場合はマイクの許可が必要です。会議や通話を記録する際は、参加者の同意を得たうえでご利用ください。
```

## キーワード

```text
画面収録,画面録画,録画,録音,内部音声,システム音声,マイク,会議,ミーティング,議事録,文字起こし,要約,自動録画,メニューバー
```

(66 文字 / 172 バイト。Apple の資料は「100 文字」と「100 バイト」で揺れており
(CodeRabbit レビュー指摘で確認)、確実なのは**このアプリで 71 文字 / 180 バイトが
受理・審査通過した実績**。そのため ja は実績のある 180 バイト以内に収めた
(それより厳しい 100 バイトに合わせると入れられる語が大きく減る)。旧キーワードから
M4A を外し、録画・要約・自動録画を追加。スクリーンレコーダーは画面収録・画面録画・
録画が検索語をカバーするため外した)

## 新着情報 (0.8.5)

0.8.4 からの変更はユーザー可視の 1 件: 録画エンジンを kilde-cli-swift **v0.9.0** に更新し、
画面キャプチャの中断からの**自動リスタート**を取り込んだ (kilde-cli-swift#73 / issue #304)。
ディスプレイ再構成・収録ウィンドウの消失などで SCK がストリームを自停止したとき、
v0.8.2 まではその時点で録画を確定していたが、上限付き (3 回) のリスタートで
同一ファイルへの録画を継続する。GUI は再開に成功したら «自動で再開» 文面の通知に切り替える
(\`Summary.captureRestartCount\`)。UI の用語は Localizable.xcstrings の ja (キー) と一致させている。

```text
録画中にディスプレイの接続や解像度の変更などで画面キャプチャが中断されても、自動で再開して同じファイルに録画を続けるようになりました。自動で再開できなかった場合は、これまでどおり中断時点までの内容を保存してお知らせします。
```

## 新着情報 (0.10.0)

0.9.0 からのユーザー可視の変更は 2 件。**録画ライブラリから後から文字起こし・議事録を
作成できる**ようになった (issue #321) — 文字起こしを無効にして録画した録画も、ライブラリの
ウィンドウからその場で文字起こし・要約を実行して内容を確認できる。もう 1 件はエンジンを
kilde-cli-swift **v0.10.0** に更新 (issue #316) して既定ビットレートを再調整したことで
(kilde-cli-swift#86)、既定の mp4 録画が 1 時間あたり約 200MB 圏になる。
«config.json でビットレートを上げる» 回避策は MAS 版ではサンドボックスのために使えないので
What's New には書かない。

```text
録画ライブラリから、文字起こしをオフで録った録画にも後から文字起こしや議事録 (要約) を作成できるようになりました。あわせて、録画ファイルの既定のサイズを 1 時間あたり約 200MB まで小さくしました。
```
