# App Store 메타데이터 — 한국어 (ko)

**이슈 #160 (2026-09-26) 업데이트**: 전사·요약 (0.8.1)을 앞세운 문안으로 다시 쓰고,
설명과 키워드에서 제3자 상표(회의 서비스명 등)를 뺐다. 부제도
「시스템 사운드 녹화·전사까지」로 변경. 이전 문안은 git 히스토리와
[metrics.md](metrics.md)의 변경 전 기록 참조.

## 앱 이름 (≤30)

```text
kilde — 화면·소리 녹화
```

## 부제 (≤30)

```text
시스템 사운드 녹화·전사까지
```

(15자. 차별점(시스템 사운드)과 새 기능(전사)을 한 문장에 담았다.
이전 부제 「시스템 사운드와 마이크를 한 파일에」)

## 설명

```text
kilde는 화면과 소리를 함께 녹화하는 오픈 소스 macOS 앱입니다.
기본 화면 녹화로는 잡을 수 없는 '시스템 사운드'까지
클릭 한 번으로 녹화합니다.

회의 녹화에
온라인 회의를 상대방의 목소리(시스템 사운드)와 내 목소리(마이크)를
한 파일에 믹스해 녹화합니다. 오디오 소스를 트랙별로 분리해 녹화하면
전사에 화자 라벨(나 / 상대)이 붙습니다. 회의 창이 감지되면 자동으로
녹화를 시작하는 옵션도 있습니다(기본 꺼짐).

녹화 후 전사와 요약 (macOS 26 이상)
녹화가 끝나면 이 Mac 안에서만 처리하는 전사를 녹화 파일 옆에
Markdown으로 저장합니다. Apple Intelligence가 켜진 Mac에서는
회의 요약도 만들 수 있습니다. 오디오와 전사 내용은 외부로
전송되지 않습니다.

전문 검색으로 바로 그 순간으로
전사 내용은 녹화 라이브러리에서 전문 검색할 수 있고, 검색어가
나온 시점부터 바로 재생할 수 있어 긴 녹화를 오가며 찾을 필요가
없습니다.

주요 기능
·추가 설정 없이 화면 + 시스템 사운드 녹화 (네이티브 ScreenCaptureKit)
·마이크나 오디오 인터페이스 등 입력 기기 동시 녹음 (믹스 / 트랙 분리)
·창 단위 캡처 — 소리도 해당 앱으로 범위 한정
·오디오만 녹음 (M4A), 추가 드라이버 불필요
·전역 단축키나 단축어 앱으로 시작·중지
·녹화 중단이든 앱 종료든 파일은 항상 끝까지 기록됩니다

개인정보
녹화 내용과 전사는 내 Mac에만 남습니다. 개발자에게 전송되는 것은
실행 횟수 등 집계된 사용 통계와 앱이 비정상 종료했을 때의 충돌
보고서뿐이며, 녹화 내용이나 파일 자체는 절대 전송되지 않습니다.
자세한 내용은 github.com/kilde-team/kilde의 PRIVACY.md를 참조하세요.

시스템 요구 사항
macOS 14 이상 (Apple Silicon). 전사와 요약은 macOS 26 이상 필요.
무료, 광고 없음, 오픈 소스 (MIT).

`kilde` 명령줄 도구와 동일한 녹화 엔진을 공유합니다.
자세한 내용: https://github.com/kilde-team/kilde
```

## 새로운 기능 (0.8.5)

0.8.4 이후 사용자가 볼 수 있는 변경 1건: 녹화 엔진을 kilde-cli-swift **v0.9.0** 으로
업데이트하여 캡처 중단 후의 **자동 재시작**을 추가했습니다 (kilde-cli-swift#73 /
issue #304). ScreenCaptureKit이 스트림을 스스로 중단하면 (예: 디스플레이 재구성)
v0.8.2에서는 그 시점에 녹화를 확정했지만, 이제 엔진이 같은 파일에 최대 3회까지
재개하여 계속 녹화합니다. GUI는 Summary.captureRestartCount로 «자동으로 재개됨»
문구의 알림으로 전환합니다.

```text
이제 녹화 중 디스플레이 연결이나 해상도 변경 등으로 화면 캡처가 중단되어도 자동으로 다시 시작하여 같은 파일에 녹화를 계속합니다. 캡처를 재개할 수 없는 경우에는 기존과 같이 중단 시점까지의 내용을 저장하고 알려드립니다.
```

## 새로운 기능 (0.9.0)

0.8.5 이후 기능 변경은 없음: 이번 제출은 App Store 버전 번호를 직접 배포판 v0.9.0에
맞추는 것 (issue #307 / issue #310). 캡처 중단 후 자동 재시작 (0.8.5)과 «폴더 열기»
버튼 (0.8.4)은 이미 App Store 사용자에게 전달되었으므로, 새 소식 문구는 유지보수
릴리스라는 점만 적는다.

```text
이 버전은 유지보수 릴리스입니다. 버전 번호를 직접 배포판과 일치시켰으며 녹화 기능의 변경은 없습니다.
```

## 새로운 기능 (0.10.0)

0.9.0 이후 사용자에게 보이는 변경 2건. 텍스트 변환을 끄고 녹화한 녹화물도 라이브러리
창에서 바로 사후 텍스트 변환과 회의록(요약)을 만들 수 있게 되었다 (issue #321).
엔진을 kilde-cli-swift **v0.10.0**으로 업데이트하고 (issue #316) 기본 비트레이트를
재조정하여 (kilde-cli-swift#86) 기본 mp4 녹화가 시간당 약 200MB 수준이 되었다.
«config.json에서 비트레이트를 올리는» 우회책은 샌드박스인 App Store 빌드에는
해당되지 않으므로 새 소식에는 쓰지 않는다.

```text
이제 녹화 라이브러리에서 텍스트 변환을 끄고 녹화한 녹화물도 나중에 텍스트 변환이나 회의록(요약)을 만들 수 있습니다 (텍스트 변환은 macOS 26 이상, 요약은 Apple Intelligence 필요). 기본 설정의 H.264 MP4 녹화 파일도 시간당 약 200MB로 훨씬 작아졌습니다.
```
