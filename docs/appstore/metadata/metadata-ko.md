## 앱 이름 (≤30)

```text
kilde — 화면·소리 녹화
```

## 부제 (≤30)

```text
시스템 사운드 녹화·전사까지
```

(15자. 차별점(시스템 사운드)과 새 기능(전사)을 한 문장에 담았다.
이전 부제 「시스템 사운드와 마이크를 한 파일에」)

## 설명

```text
kilde는 화면과 소리를 함께 녹화하는 오픈 소스 macOS 앱입니다.
기본 화면 녹화로는 잡을 수 없는 '시스템 사운드'까지
클릭 한 번으로 녹화합니다.

회의 녹화에
온라인 회의를 상대방의 목소리(시스템 사운드)와 내 목소리(마이크)를
한 파일에 믹스해 녹화합니다. 오디오 소스를 트랙별로 분리해 녹화하면
전사에 화자 라벨(나 / 상대)이 붙습니다. 회의 창이 감지되면 자동으로
녹화를 시작하는 옵션도 있습니다(기본 꺼짐).

녹화 후 전사와 요약 (macOS 26 이상)
녹화가 끝나면 이 Mac 안에서만 처리하는 전사를 녹화 파일 옆에
Markdown으로 저장합니다. Apple Intelligence가 켜진 Mac에서는
회의 요약도 만들 수 있습니다. 오디오와 전사 내용은 외부로
전송되지 않습니다.

전문 검색으로 바로 그 순간으로
전사 내용은 녹화 라이브러리에서 전문 검색할 수 있고, 검색어가
나온 시점부터 바로 재생할 수 있어 긴 녹화를 오가며 찾을 필요가
없습니다.

주요 기능
·추가 설정 없이 화면 + 시스템 사운드 녹화 (네이티브 ScreenCaptureKit)
·마이크나 오디오 인터페이스 등 입력 기기 동시 녹음 (믹스 / 트랙 분리)
·창 단위 캡처 — 소리도 해당 앱으로 범위 한정
·오디오만 녹음 (M4A), 추가 드라이버 불필요
·전역 단축키나 단축어 앱으로 시작·중지
·녹화 중단이든 앱 종료든 파일은 항상 끝까지 기록됩니다

개인정보
녹화 내용과 전사는 내 Mac에만 남습니다. 개발자에게 전송되는 것은
실행 횟수 등 집계된 사용 통계와 앱이 비정상 종료했을 때의 충돌
보고서뿐이며, 녹화 내용이나 파일 자체는 절대 전송되지 않습니다.
자세한 내용은 github.com/kilde-team/kilde의 PRIVACY.md를 참조하세요.

시스템 요구 사항
macOS 14 이상 (Apple Silicon). 전사와 요약은 macOS 26 이상 필요.
무료, 광고 없음, 오픈 소스 (MIT).

`kilde` 명령줄 도구와 동일한 녹화 엔진을 공유합니다.
자세한 내용: https://github.com/kilde-team/kilde
```


## 새로운 기능 (0.16.0)

MAS 0.15.0 이후 사용자에게 보이는 변화는 1 건이다. 팝오버에서 실행 중인 앱을
선택하면 그 앱의 오디오만 녹음할 수 있게 됐다 (issue #364 / PR #366). 이 기능은
**macOS 15 이상에서 사용할 수 있다** (엔진 kilde-cli-swift v0.16.0의
Audio Process Tap — pin은 PR #366에서 갱신됨). macOS 14.x에서는 «앱 오디오
선택…» UI 자체가 표시되지 않는다. 마이크와는 함께 사용할 수 있고, 앱 오디오와
시스템 오디오는 동시에 녹음할 수 없다 (앱을 선택하면 시스템 오디오가 해제된다).
선택은 패널에서 녹화를 시작할 때 bundleID로 저장되고 («이 오디오·저장 위치 선택을
기본값으로 저장»도 같음) 다음 실행에도 이어진다 (대상이 실행 중이 아니면
«(실행 중 아님)» 표시와 녹화 시작 시 안내가 나온다).

```text
팝오버에서 실행 중인 앱을 선택하면 그 앱의 오디오만 녹음할 수 있습니다 (이 기능은 macOS 15 이상이 필요합니다). 마이크와 함께 사용할 수 있으며, 앱 오디오와 시스템 오디오는 동시에 녹음할 수 없습니다. 녹화를 시작하면 선택이 저장되어 다음 실행에도 유지됩니다.
```

## 새로운 기능 (0.17.0)

MAS 0.16.0 이후 사용자에게 보이는 변화는 없다. 내부 개선으로, 녹화를 시작할 때
