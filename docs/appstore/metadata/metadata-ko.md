# App Store 메타데이터 — 한국어 (ko)

## 앱 이름 (≤30)

```
kilde — 화면·소리 녹화
```

## 부제 (≤30)

```
QuickTime이 못 잡는 소리까지
```

## 설명

```
kilde는 화면과 소리를 함께 녹화하는 오픈 소스 macOS 앱입니다.
QuickTime Player의 화면 녹화로는 잡을 수 없는 '시스템 사운드'까지
클릭 한 번으로 녹화합니다.

회의 녹화에
Zoom / Google Meet / Teams 회의를 상대방의 목소리(시스템 사운드)와
내 목소리(마이크)를 한 파일에 믹스해 녹화합니다. 창을 고르면 그 앱의
소리만 녹음되고 알림음 등 다른 앱의 소리는 들어가지 않습니다.

주요 기능
・추가 설정 없이 화면 + 시스템 사운드 녹화 (네이티브 ScreenCaptureKit)
・마이크나 BlackHole 등 입력 기기 동시 녹음 (믹스 / 트랙 분리)
・창 단위 캡처 — 소리도 해당 앱으로 범위 한정
・오디오만 녹음 (M4A), 추가 드라이버 불필요
・monitor 모드: 녹음하면서 같은 소리를 들을 수 있음 (BlackHole 필요)
・HDR 녹화 (macOS 15+, HEVC Main10)
・녹화 중단이든 앱 종료든 파일은 항상 끝까지 기록됩니다

개인정보
녹화 내용은 내 Mac에만 남습니다. 개발자에게 전송되는 것은 실행 횟수
등 집계된 사용 통계뿐이며, 녹화 내용이나 파일 자체는 절대 전송되지
않습니다. 자세한 내용은 github.com/kilde-team/kilde의 PRIVACY.md를
참조하세요.

시스템 요구 사항
macOS 14 이상 (Apple Silicon). 무료, 광고 없음, 오픈 소스 (MIT).

`kilde` 명령줄 도구와 동일한 녹화 엔진을 공유합니다.
자세한 내용: https://github.com/kilde-team/kilde
```
