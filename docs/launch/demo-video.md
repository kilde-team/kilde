# デモ動画 — 絵コンテと撮影チェックリスト (kilde-site#1)

60 秒のデモ動画の絵コンテ。録画は人間が行う (docs/launch/README.md のルール)。
このファイルが [kilde-site#1](https://github.com/kilde-team/kilde-site/issues/1)
の素材表 «デモ動画 ❌» を埋める。

## 制約 (kilde-site#1 のスコープより)

- **実在の会議サービスのロゴ・ウィンドウ名を映さない** (App Store 審査対策)。会議は
  ダミーウィンドウで演じる (下のチェックリスト参照)
- 日本語版と英語版 = **同一映像 + 字幕の差し替え**で作る (撮り直し不要)
- App Store のプレビュー動画は **30 秒以内** — 60 秒のマスターからショット 1〜5 を
  短縮した派生版を切り出す
- Product Hunt のギャラリーは 16:9 (最低 1270×760)。撮影は既存スクショと同じ
  2880×1800 (16:10) で行い、16:9 へのクロップは投稿者が実施 (README.md の素材表どおり)

- ショット 1 の自動検出トーストは再現性が揺れるため主経路にしない。余裕があれば
  撮影し、ショット 1 の代替テイクとして残す (採用は編集時判断)

## 撮影チェックリスト (録画担当者用)

### 事前準備

- [ ] **ダミー会議ウィンドウ**: 実在サービスを使わない。ウィンドウ名 «Design Weekly»、
  参加者名はダミー («A. Sato» 等)。Zoom 等の実物・ロゴ・通知は画面に入らない位置で
- [ ] デスクトップを整える: 壁紙は無地、ファイル・通知 (Do Not Disturb ON)・
  個人情報 (名前・メール・ブックマーク) が写らないこと。メニューバーの他アプリの
  アイコンも目立つものは非表示にする
- [ ] ダミー発話: 会議の音は実在の音源を使わず、読み上げ (例: `say -o` で作った音声) を
  スピーカー再生してシステム音声として録る。内容は偶発的な実会議の話題と無関係な
  スクリプト (プロダクト名を出さない)
- [ ] 録画設定: 2880×1800、60fps、H.264。デモの GUI 操作はあらかじめ 2〜3 回リハーサル
- [ ] kilde 側: 出力先をきれいなフォルダに。ライブラリにはデモ用の録画だけが並ぶ状態に
  (事前にテスト録画を 1 本入れておくとショット 5 が安定する)

### 撮影・納品

- [ ] ショットごとに個別テイクで撮り、編集で繋ぐ (ロングテイク 1 本より失敗しない)
- [ ] 字幕は ja / en の 2 版を焼く (または SRT を 2 組)。動画本体は 1 本
- [ ] 書き出し: マスター 60 秒 + App Store プレビュー用 15〜30 秒 (ショット 1〜5 を
  短縮、エンドカードは kilde.site ではなくアプリ名のみに差し替え)
- [ ] ファイル名: `kilde-demo-60s.mp4` / `kilde-demo-appstore.mp4`。リポジトリには
  コミットしない (素材は kilde-site 側で管理 — AGENTS.md「検証に使う音声・録画ファイルは
  リポジトリにコミットしない」に準拠)
- [ ] kilde.site への掲載 (トップ、日英切替、遅延読み込み) は kilde-site#1 の受け入れ条件 —
  サイト側の実装 issue で対応

## 事実の正本

- 機能の記述は README.md / docs/DESIGN.md のとおり («QuickTime Player が録れない
  システム音声» / «Ctrl+C でもファイナライズ» / 文字起こしは macOS 26 の Speech /
  要約はオンデバイスの Foundation Models)
- «一切送らない» 系の主張は PRIVACY.md の記述範囲で言う。超えた言い方 («100% 安全» 等)
  はしない
